# 3D Hero Composition Families

## right-dominant-cutaway

Use when one technical object should dominate the page.

Composition rules:
- keep narrative compact on the left
- place one large cutaway object on the right
- leave negative space around the object
- use sparse perimeter labels only where they clarify structure

Avoid:
- cards under the model
- a second equal-weight module
- a heavy footer

## exploded-stack

Use when the object is best explained as multiple layers that separate but still read as one system.

Composition rules:
- separate layers vertically or diagonally
- keep gaps disciplined and structural
- let one or two labels explain the stack logic
- keep left-side narrative short and strategic

Avoid:
- too many thin layers
- labels on every layer
- turning the stack into a long infographic

## layered-chip-slab

Use when the object is a chip, die, substrate, or package-like slab.

Composition rules:
- emphasize one slab-like object with visible thickness
- show substrate and die hierarchy clearly
- use seams, etched detail, and restrained highlights
- keep annotation sparse and close to the object

Avoid:
- flat square chip icon
- giant paragraphs beside the slab
- strong decorative glow without structure

## platform-block-diagram-3d

Use when the object is a platform stack or architectural block system.

Composition rules:
- render the platform as one layered structural object
- show hierarchy through elevation and spacing, not many arrows
- let a few labels explain the blocks
- preserve a board-ready, authored feel

Avoid:
- flat block diagram
- dense connector spaghetti
- too many equal rectangles
