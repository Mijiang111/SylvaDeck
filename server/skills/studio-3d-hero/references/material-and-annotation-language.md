# Material and Annotation Language

Use a restrained executive material language.

Material cues:
- satin silicon
- etched metallic seams
- machined shell surfaces
- disciplined highlights
- soft but directional shadows
- visible thickness on primary planes

Annotation cues:
- short technical callouts
- anchored side labels
- perimeter labels for fabrics or cutaways
- etched inline labels only when the object family supports them

Tone rules:
- the object should feel inspectable and fabricated
- labels should clarify the object, not narrate the slide
- keep the page authored, calm, and premium

Avoid:
- game UI
- sci-fi poster glow
- random neon gradients
- dashboard chrome
- copy-heavy annotations
