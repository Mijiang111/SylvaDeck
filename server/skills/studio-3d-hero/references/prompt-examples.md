# 3D Hero Prompt Examples

## chip-die-substrate

Brief fragment:
- explain the layered architecture of the substrate, compute die, and memory fabric

Recommended direction:
- object family: `chip-die-substrate`
- composition family: `layered-chip-slab`
- page contract: one chip slab with visible thickness, etched grid, seam language, and two tight labels

Avoid:
- flat chip icon
- text below the slab
- many small side cards

## platform-stack

Brief fragment:
- explain how the orchestration, runtime, and data layers form one integrated platform

Recommended direction:
- object family: `platform-stack`
- composition family: `exploded-stack` or `platform-block-diagram-3d`
- page contract: one integrated stack with clear hierarchy and no dashboard clutter

Avoid:
- flat flowchart
- too many equal rectangles
- labels on every layer

## interconnect-fabric

Brief fragment:
- show why the interconnect fabric and routing topology matter for latency and power

Recommended direction:
- object family: `interconnect-fabric`
- composition family: `right-dominant-cutaway`
- page contract: one structural fabric object with visible lanes, bridges, and sparse perimeter labels

Avoid:
- node cloud wallpaper
- bright neon network art
- paragraphs under the object
