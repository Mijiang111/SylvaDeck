# Studio Thinking Mode: Strategy

Use this as a light thinking plugin, not as the default worldview.

## When to use

- The brief explicitly asks for a recommendation, strategic direction, prioritization, investor framing, board framing, or leadership decision support.
- The audience and desired output are clearly decision-oriented.

## Page grammar

- Use thesis / proof / implication / decision grammar.
- Recommendation-first is allowed, but only when the brief clearly asks for it.
- One page should still answer one question, land one claim, and use one dominant proof pattern.

## Guardrails

- Do not inject strategy language into briefs that are really case studies, research talks, or neutral explanatory decks.
- When page count is fixed, delete weak secondary material instead of squeezing in a second strategic argument.
- Keep recommendations evidence-led and specific.
