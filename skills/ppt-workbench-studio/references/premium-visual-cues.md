# Premium Visual Cues

Use this reference when the user wants a page to feel more refined, more publication-like, or more intentional.

The goal is not to add luxury adjectives. The goal is to use phrases that produce better visual decisions.

## Strong phrases

These usually help:

- `single dominant visual`
- `one visual thesis per page`
- `publication-quality figure`
- `editorial spacing`
- `thin-line data styling`
- `quiet secondary text`
- `restrained annotation`
- `high signal, low chrome`
- `strong hierarchy`
- `hero + evidence rail`
- `chart-led`
- `figure-led`
- `matrix-first`

## Weak phrases

These usually do not help much:

- `more premium`
- `more top-tier`
- `more advanced`
- `more beautiful`
- `make it luxury`

If a phrase does not imply structure, hierarchy, or restraint, it is probably weak.

## Good replacements

Instead of:

- `make it more premium`

Use:

- `use one dominant visual with quiet secondary text`
- `keep the page high signal, low chrome`
- `avoid equal-weight cards`

Instead of:

- `make it feel top-tier`

Use:

- `make the page feel publication-like with restrained annotation`
- `use editorial spacing and strong hierarchy`

Instead of:

- `make it more advanced`

Use:

- `use a chart-led page with sparse callouts`
- `use a figure-led method page with one dominant central object`

## Anti-pattern language that helps

These are often as important as the positive cue:

- `not a dashboard`
- `not equal-weight cards`
- `not a memo-style wall of text`
- `not a generic icon row`
- `not several competing mini-charts`

## High-end visual outcomes usually share these traits

- one obvious focal object
- secondary text that stays quiet
- fewer decorative surfaces
- strong scale contrast
- short, directional annotation

## Practical usage

Good prompt fragment:

```text
Visual thesis:
- One publication-quality figure should dominate the page

Anti-patterns:
- Do not use equal-weight cards or dashboard clutter
```

This is stronger than:

```text
Make it look premium and advanced
```
