# Alpha feedback thread

Thanks for trying this project.

I’m open-sourcing it early because I want real feedback while it is still rough, especially around:

- setup blockers
- weak or broken generation results
- confusing template workbench interactions

If you are leaving feedback, it helps a lot if you include:

- your OS
- Node and pnpm versions
- whether you had a local AI agent configured
- the prompt or task you were trying
- screenshots or short recordings if the issue is visual

This repo is still alpha, so small rough edges are expected. What I care about most right now is understanding where people get blocked or confused fastest.
