# Soft launch post

I just open-sourced an early alpha of my local-first AI presentation workbench.

It can generate and refine 16:9 slide-style pages, and it also has a template workbench for building reusable page shapes.

It definitely still has rough edges, so I’m sharing it quietly and mostly hoping for honest feedback.

If you try it and hit setup problems, weak output, or confusing template behavior, I’d really appreciate an issue.
